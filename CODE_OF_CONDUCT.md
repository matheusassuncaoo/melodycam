# Code of Conduct / Código de Conduta

## Our pledge / Nosso compromisso

We want Melodycam to be a welcoming, harassment-free project for everyone,
regardless of age, body, ability, ethnicity, gender identity, experience level,
nationality, appearance, religion or orientation.

Queremos um projeto acolhedor e livre de assédio para todas as pessoas.

## Expected behavior / Comportamento esperado

- Be kind, patient and respectful. / Seja gentil, paciente e respeitoso.
- Give and accept constructive feedback gracefully. / Dê e receba críticas construtivas.
- Focus on what is best for the project and its community. / Foque no que é melhor para o projeto.
- Credit other people's work. / Dê crédito ao trabalho dos outros.

## Unacceptable behavior / Comportamento inaceitável

- Harassment, insults, discrimination or personal attacks. / Assédio, insultos, discriminação ou ataques pessoais.
- Publishing others' private information without permission. / Expor informações privadas de terceiros.
- Sexualized language or attention. / Linguagem ou atenção sexualizada.
- Any conduct that would reasonably be considered inappropriate in a professional setting.

## Enforcement / Aplicação

Maintainers may edit or remove comments, commits, issues and contributions that
violate this code, and may restrict participation. Report concerns by opening a
private security advisory or contacting the maintainer through the GitHub profile
<https://github.com/matheusassuncaoo>.

This Code of Conduct is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
