# Contribuindo com o Melodycam

Obrigado por querer contribuir. Antes de implementar, confira a [especificação](docs/product-spec.md) e o [fluxo Git](docs/git-workflow.md).

1. Abra uma issue para descrever o problema e um critério de aceite observável.
2. Crie `feat/<nome>` ou `fix/<nome>` a partir de `develop`.
3. Execute `npm ci` e `npm run build` antes do pull request.
4. Para mudanças de gesto ou áudio, descreva navegador, sistema, câmera ou dispositivo de áudio e o resultado do teste manual.
5. Abra o pull request contra `develop` e relacione a issue.

Evite incluir vídeos de câmera, gravações de pessoas ou músicas de terceiros no repositório sem autorização e licença apropriadas. O código usa a licença MIT do repositório. Cada peça ou gravação incluída na biblioteca precisa ter autoria e licença próprias.
